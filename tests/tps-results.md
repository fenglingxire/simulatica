# 骨粉机 200 TPS 测试结果

2026-10-01，开发客户端 Minecraft 26.2，使用用户提供的原理图文件。文件只读，在内存中向下扩展边界，激活原有拉杆；未添加红石块。先预热 1,200 个模拟 tick，再测量现实一分钟。

| 项目 | 最终结果 |
| --- | ---: |
| 目标 TPS | 200 |
| 现实测量时长 | 60.011 秒 |
| 执行的模拟 tick | 8,921 |
| 推进的模拟时间 | 446.05 秒（7 分 26 秒） |
| 实际 TPS | 148.66 |
| 最终输出端收集的骨粉 | 431 |
| 正常速度产量 | 3,493.4 个/小时 |
| 观察到的苔藓方块变化 | 13,335 |

机器两段半分钟内均持续产出，拉杆和红石灯保持激活，停止后模拟 tick 不再增加。产量从首个物品到达开始按模拟 tick 计时，因此与整段测量时长直接相除略有不同。

机器运行检查通过；实际速度受客户端计算预算和性能限制，**未达到现实一分钟推进模拟十分钟**。声音及方块事件在加速时按客户端 tick 采样，方块与实体逻辑仍执行完整模拟 tick。

活塞动画回归通过：47 次移动活塞头提交、47 次被推动方块提交，48 个渲染案例通过。测试未运行 1 TPS 或其它倍率的骨粉机场景。

复测：`./gradlew.bat -I tests/tps-smoke.gradle runClient`。原始结果保存在 `run/tps-scene-result.txt`。
