# 投影模拟-新视界 Simulatica: New Horizon

> 让 Litematica 的原理图投影"活"起来 —— 在客户端后台运行一个真实模拟服务器，把投影范围内的方块和实体复制进去，按原版逻辑真实运转，并把每一步变化实时回写到投影上。

**本分支：`Simulatica-New-Horizon`** —— 基于 [Simulatica](https://github.com/hotpad100c/simulatica)（原作者 Ryan100C）的 **Minecraft 26.2 二改版**，在 26.2（Fabric）适配基础上进一步增强了假人系统、模拟自然刷怪、交互与战斗等能力。原 1.21.11 版本在 `master` 分支。

- 依赖：Fabric Loader 0.19.5 · fabric-api · malilib 0.29.6 · litematica 0.28.8 · Java 25
- 图例：**🆕 新增** = 本二改版（相对原版 1.21.11 模组）新加入的功能；无标注者为原版已有功能。
- mod 由 AI 工具编写升级，可能会出现难以预料的错误。

---

## 一、这个模组是干什么的

Simulatica 让 **Litematica 的原理图投影"活"起来**——它在你的客户端后台运行一个真实的模拟服务器，把投影范围内的方块和实体复制进去，按原版逻辑真实运转（红石、活塞、容器、实体 AI 等），并把每一步变化实时回写到投影上。你可以对着投影开箱子、按按钮、扔物品、改命令方块，**不消耗真实物品，也不改动真实世界**。适合在创造档里预演红石机器、验证农场效率、调试命令方块。

## 🆕 二、本二改版新增功能

### 每个投影独立 TPS

`/simulatica tps "放置名称" 200` 将指定投影设为目标 200 TPS（10 倍速）；省略数值查询目标 TPS。范围为整数 1–1000，默认 20，名称需使用 Litematica 的放置名称，重名时先改名。设置按世界与放置名称保存，停止再启动及退出重进仍生效；改名后使用新名称的配置。

每个投影拥有独立模拟世界，同一投影的子区域保持联动，不同投影之间不再交换红石、物品或实体。真实世界速度不变；客户端暂停时模拟暂停。计算预算不足时实际 TPS 会降低；指令提示仅显示目标 TPS。

效率按实际推进的模拟 tick 换算为正常 20 TPS 下的每小时产量，分别显示各投影和全局同色汇总。全局产量是各投影正常速度产量之和。改速不重置计数，停止时冻结，重启继续；退出世界清空统计。

`/simulatica execute ...` 使用当前选中的运行投影，只有一个运行投影时自动选择。

### 假人系统（Bot）

在投影配置界面里召唤假人（ServerPlayer），让它替你操作模拟机器：

- **召唤 / 清理 / 传送到玩家**，游戏模式可切换（创造 / 生存）
- **动作控制**：攻击 / 使用 / 跳跃（间隔或长按）、潜行 / 疾跑 / 前进、单击左键 / 单击右键、丢弃 / 换手 / 停止
- **飞行**：创造模式假人离地较远时自动飞行，且与玩家飞行状态同步
- **完整物理与战斗**：重力、受击动画、死亡倒地、经验吸收，武器伤害 / 横扫 / 暴击 / 附魔全部生效
- **假人背包**：两段式界面（上：假人背包含盔甲副手，下：玩家背包），物品可在玩家 ↔ 假人之间转移
- **空手右键准星指向假人** → 直接打开其背包

### 模拟自然刷怪 🆕

模拟世界按真实 biome 与光照自然刷怪（露天不刷、暗室可刷、火把/岩浆亮度正确），可直接验证刷怪塔 / 农场效率。

### 交互与战斗增强 🆕

- 攻击走原版战斗规则：冷却、暴击、附魔、横扫、击退全部生效（武器不掉耐久）
- 指令栏 TAB 补全 + 候选列表鼠标点击选取

### 漏斗计数器 🆕（参考 Carpet hopperCounters）

- 漏斗朝向（FACING）方向铺羊毛，物品流经漏斗时按羊毛颜色累计计数并被吞掉
- 控制面板「漏斗计数器」：查看各颜色计数 / 一键重置

## 三、上手流程（4 步）
### 第 1 步：放置原理图

用 Litematica 加载并放置原理图（`M` 打开主菜单 → 加载原理图 → 创建放置/Placement），确保投影显示在世界中。

### 第 2 步：启动模拟

```
/simulatica start              # 启动全部已加载放置
/simulatica start <原理图名>    # 只启动某一个（支持 Tab 补全）
```

### 第 3 步：切换到「模拟交互」工具模式

Simulatica 给 Litematica 新增了一个工具模式 **模拟交互（Simulate Interaction）**。用 Litematica 的工具模式切换键（默认 `Ctrl + 滚轮`，或热键里搜 "Tool Mode"）切到它。**只有在此模式下，下面的交互才会生效。**

### 第 4 步：与投影交互

| 操作           | 效果                                                                       |
| ------------ | ------------------------------------------------------------------------ |
| **左键** 投影方块  | 破坏该模拟方块。**手持剑时不破坏任何方块**，只挥动（🆕 避免挥空误删投影内容）                               |
| **左键** 模拟实体  | 攻击（10 格距离）。🆕 走原版战斗规则：冷却、暴击、附魔、击退、武器音效全部生效，武器不掉耐久                        |
| **右键** 投影方块  | 使用方块：开容器、按按钮、拉拉杆、开命令方块                                                   |
| **右键** 模拟实体  | 🆕 与生物交互：打火石点苦力怕、铁锭修铁傀儡、喂食繁殖等，不消耗物品                                      |
| **右键** 手持物品  | 在模拟位置使用（放置/点火等），不消耗物品。🆕 区域**底部也可放置**（底部地面仅对实体存在的碰撞面）                    |
| **右键** 投射物物品 | 🆕 弓/弩/三叉戟在模拟世界拉弓蓄力；雪球/鸡蛋/末影珍珠/喷溅&滞留药水/经验瓶/风弹/钓竿直接投掷，投射物生成在模拟世界。均不消耗真实物品 |
| **Q（丢弃键）**   | 把手中物品扔进模拟世界（不消耗），测试吸收/漏斗拾取                                               |
| 容器界面         | 放入物品 → 关闭时回滚；取出物品 → 仅创造模式有效                                              |
| 命令方块界面       | 直接打开/编辑/保存，改动只作用于模拟世界                                                    |

停止：

```
/simulatica stop            # 停止全部
/simulatica stop <名称>      # 停止指定放置
```

## 三、`/simulatica` 指令详解

```
/simulatica                      🆕 打开游戏内控制面板（菜单）
├── start [placement_name]      启动模拟（无参数 = 全部）
├── stop [placement_name]       停止模拟（无参数 = 全部）
├── status                      查看运行状态
├── absorb [on|off]             🆕 掉落物吸收开关（无参数 = 切换）
├── purge                       🆕 清除卡出投影边界的实体
├── execute <command>           在模拟服务器里执行原版指令
└── server
    ├── start                   仅启动后台模拟服务器
    ├── stop                    停止全部模拟并关闭模拟服务器
    └── selftest                运行自检诊断
```

### 🆕 控制面板（裸输 `/simulatica` 打开）

分左右两区，打开时模拟继续运行：

- **左列 全局操作**：启动/停止全部、掉落物吸收开关、清除越界实体、自检诊断；
- **右列 单个投影**：每个放置一行，● 运行中 / ○ 未启动，单独启停；列表过长用滚轮翻页；
- 顶部状态行：活动数 / 等待数 / 投影总数。

### `/simulatica start [placement_name]`

- 把放置区域复制进模拟世界并开始 tick；首次启动大投影需一两秒。
- 两个运行中的模拟区域**不允许重叠**（相邻、贴边可以）；冲突时放置被弹回原位并提示。
- 移动/旋转/镜像 placement，模拟整体平移跟随。

### `/simulatica stop [placement_name]`

- 停止模拟、清空模拟区域、释放强加载区块。
- 方块改动保留在投影里；🆕 模拟中召唤/生成的**生物和掉落物以最后状态留存在投影中**，再次启动时被重新接管、不会重复。

### `/simulatica status`

显示：活动模拟数量；等待启动（pending）的区域及原因；每个模拟的名称、坐标范围、实体数量。

### 🆕 `/simulatica absorb [on|off]`

掉落物吸收开关。开启后，模拟区域内掉落物一接触玩家就消失并播放拾取音效，**但不进背包**：

- 经验球、箭矢（含三叉戟）同样吸收——经验值与物品都不给玩家；🆕 自己射出插在方块上的箭（含创造模式射出的）也能吸走；骷髅射的箭按原版本就不可拾取，不吸；
- 刚扔入的物品（约 2 秒拾取延迟内）、刚射出还在抖动的箭（7 tick 内）不会被吸，机器仍能取走。

### 🆕 `/simulatica purge`

清除所有卡出投影边界的实体（瞬移、历史版本遗留等原因跑出区域的生物/掉落物），聊天栏报告清除数量。边界墙对常规移动是封闭的，此指令处理瞬移类例外。

### `/simulatica execute <command>`

在模拟服务器上执行任意原版指令（OWNER 权限，Tab 补全）：

```
/simulatica execute time set day
/simulatica execute fill 0 64 0 10 64 10 stone
/simulatica execute summon creeper ~ ~ ~
```

坐标基于模拟世界（与投影位置一致）；效果只发生在模拟里，不影响真实世界。

### `/simulatica server start / stop`

手动管理后台模拟服务器，日常不需要（start 会自动拉起）。退图/断连时全部模拟与服务器自动关闭。

### `/simulatica server selftest`

内置冒烟测试，逐项 `PASS / FAIL`（区块强加载、重力方块下落渲染）。"模拟没反应"时先跑它定位。

## 四、注意事项与限制

1. mod由AI工具编写升级，可能会出现难以预料的错误。
2. **模拟完全在客户端本地运行**：投影越大、机器越复杂，对帧率影响越明显。
4. **不改动真实世界**：所有破坏、放置、指令效果只存在于模拟与投影显示层。
5. **交互保护已移除**：不再拦截投影边界（及周边约 3 格）内的原版左键/右键交互；模拟运行期间对准投影附近的真实方块将按原版行为正常放置/破坏。
6. **物品保护**：右键使用、Q 丢出都不扣背包物品；从模拟容器取物品仅创造模式有效。
7. **区域冲突**：两个模拟区域不能重叠，重叠时后到的放置被弹回。
8. **等待启动正常**：投影重建期间显示 pending，最多等约 5 秒（100 tick）。
9. 断线/退图自动停止全部模拟并删除临时模拟世界；🆕 但生物留档文件会保留（删掉即可回到初始状态）。
10. 🆕 **攻击走原版战斗规则**：冷却、暴击、附魔、武器音效生效；武器不掉耐久。生物被击杀会播死亡声、倒地动画并留掉落物——是正常死亡，不是"凭空消失"。
11. 🆕 **生物本地留档**：停止模拟时，存活生物除保留在投影显示外，还按「放置/区域」存到本地（`<游戏目录>/simulatica/leftovers/<存档名或服务器地址>/`）；下次对同一放置启动时自动恢复。删除对应 `.nbt` 文件可让该区域下次从原理图原始状态开始。
12. **多人服务器可用**：模拟完全本地运行，其他玩家看不到你的模拟，也不会向服务器发送异常数据。
13. 🆕 **边界完全封闭**：模拟区域由四面隐形墙（上延至投影顶上方 10 格）+ 顶部封顶盖 + 底部地面围成全封闭碰撞盒，风弹等强击退也无法把生物抛出边界。生物 AI 看不见边界。
14. 🆕 **投射物已知限制**：弓、三叉戟、投掷类走完整服务端分支，命中飞行正常；**弩**因装填状态在客户端与服务端分裂，纯客户端路径下装填可能不完整，以实机为准。
15. **掉落物贴边轻微抖动属正常**：掉落物在**水/熔岩运输水道里按原版速度正常流动**；贴投影边界/底部静止时可能有轻微抖动（为保持水流运输速度与原版一致，已移除贴边防抖处理），不影响模拟正确性。

## 五、常见问题

**Q：对着投影右键/左键没反应？**  
→ 检查：① 是否切到「模拟交互」模式；② 是否已 `/simulatica start`；③ 屏幕提示（如"放置「xxx」尚未启动模拟"）。

**Q：模拟好像不动？**  
→ 先 `/simulatica status` 看是否 pending；再 `/simulatica server selftest` 自检。

**Q：能用原版指令改模拟世界的时间/天气吗？**  
→ 可以：`/simulatica execute time set day`、`/simulatica execute weather clear`。

**Q：上次模拟召唤的生物，重进存档后还在吗？**  
→ 在本地留档里，重新对同一放置启动模拟时自动恢复。

**Q：攻击生物后它直接不见了？**  
→ 是被打死了（高伤武器会一两击击杀），会留掉落物并播死亡声与倒地动画。若日志出现 `left ... while alive` 警告才是非正常逃逸，请发日志。

**Q：多人服务器里别人能看见我的模拟吗？**  
→ 不能。模拟只在你本地运行。
